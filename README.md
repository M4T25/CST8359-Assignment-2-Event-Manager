This ASP.NET Core MVC application refactors Lab 3 to query seeded registration records through Entity Framework Core. It includes `ApplicationDbContext`, `DbSet<Rsvp>`, an EF Core migration, SQLite for portable local/Azure hosting, and the required EF Core 8 packages.

Run `dotnet run --project WorkshopRsvp/WorkshopRsvp.csproj`, then open `/Workshops/Registrations`.
